# 豆瓣电影 Top250 数据采集与可视化分析

本项目是一个基于 Python 的豆瓣电影 Top250 全流程数据分析项目。不仅包含基础的网页抓取，更侧重于利用 Pandas 进行数据清洗，并结合 SQL 与 Matplotlib 进行多维度业务洞察。代码已托管至 GitHub，便于后续维护与展示。

## 项目简介
通过访问豆瓣电影 Top250 页面，抓取电影名称、评分、评价人数、导演、类型等原始信息。项目将原始的“脏数据”转化为干净的结构化数据，并导入数据库进行 SQL 聚合分析，最终输出 6 张具有业务价值的可视化图表。

## 核心功能与亮点

### 1. 数据采集与反爬应对
- 获取豆瓣电影 Top250 页面全部 10 页内容。
- 通过设置 `User-Agent` 伪装浏览器，并配合 `time.sleep()` 请求延时，有效应对基础反爬限制。
- 使用 lxml 与 XPath 精准提取所需字段（修复了由于 `<br>` 标签导致长文本被截断的坑）。

### 2. 数据清洗与预处理 (Pandas)
- **乱码解决**：输出文件采用 `utf-8-sig` 编码，彻底解决 Excel 打开 CSV 时的中文乱码问题。
- **缺失值处理**：对无短评的电影进行特定填充。
- **字段精准拆分**：利用正则表达式和字符串方法，将混杂在一起的“导演/主演/年份/国家/类型”文本，彻底拆分为独立的标准化字段。
- **数据类型转换**：将“评价人数”去除汉字并转为整型，评分转为浮点型。

### 3. SQL 聚合分析 (SQLite)
- 将清洗后的 DataFrame 快速导入 SQLite 内存数据库。
- 编写 SQL 语句进行分组聚合（如：按年代分组统计电影数量与平均评分）。

### 4. 可视化分析洞察 (Matplotlib)
生成包含 6 个子图的分析报告看板（`douban_analysis_result.png`），提供以下维度的洞察：
- **国家分布饼图**：洞悉榜单的国际化分布（美国占比近一半，本土及东亚电影紧随其后）。
- **年代分布饼图**：解决数据拥挤问题，展示 90 年代与 00 年代是高分电影爆发的黄金期。
- **导演上榜频次 Top10**：展示“作者导演”的统治力（宫崎骏、诺兰等）。
- **各年代平均评分对比**：折线图展示不同年代电影的平均质量波动。
- **各国平均评分对比**：分析哪个国家的上榜电影“平均质量”最高。
- **各类型平均评分对比**：分析哪种题材（如剧情、犯罪）更容易产出极高评分的神作。
